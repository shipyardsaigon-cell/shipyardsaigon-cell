### ⚙️ How we work — Design → Build → Test → Release

1. **Design** — user flows and key screens, then a fixed scope, timeline and price per milestone.
2. **Build** — one product across iOS, Android and web, with working builds shared regularly for early feedback.
3. **Test** — automated tests on the paths your business depends on.
4. **Release** — App Store & Google Play submission, crash monitoring, fixes and the next round of features.
